# Trybetunes

Aplicação React para pesquisar artistas e álbuns, ouvir prévias e gerenciar músicas favoritas.

## Funcionalidades e aprendizados

- Aplicação React para pesquisar artistas e álbuns
- Código organizado para estudo e evolução
- Prática das tecnologias utilizadas no repositório

## Tecnologias

- JavaScript
- React

## Como executar

```bash
git clone https://github.com/rita-moura/14-Project-Trybe-Trybetunes.git
cd 14-Project-Trybe-Trybetunes
npm install
npm start
```

### Comandos úteis

- `npm test`: executa os testes.
- `npm run build`: gera a versão de produção.
- `npm run lint`: verifica a qualidade do código.
